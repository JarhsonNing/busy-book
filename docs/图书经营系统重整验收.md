## 批量入库与 ISBN 查询（2026-10-29）

新增 MCP 工具 `taoshu_import_books` 和 `taoshu_lookup_isbn`，同时提供受应用认证保护的 `POST /api/agents/books/batch` 和 `POST /api/agents/isbn`。不增加一级页面入口，OpenCode 和其他本地 Agent 可直接调用。两个既有 Skill 已同步说明新能力，原货源和发布确认步骤保持。

批量请求使用 `{"books":[...]}`，每条字段与单本入库相同，每批 1–200 条。逐条独立事务，返回 created、matched、reused、failed 计数及每条的 bookId 或失败原因；一条失败不回滚其他条目。重试沿用 source、externalId 和相同资料，不覆盖已入库版本、库存及报价；不同版次、册次不会误合并。没有依据的版次或不合法 ISBN 按条报告失败。

ISBN 查询接受 `query`（书名）或数字 `subjectId`。按用户给定的豆瓣建议接口取得最多 20 个候选，对一个书名完全匹配候选读取详情；其他版本可再按 subjectId 查询。提取图书自身 info 区、ISBN 元数据或书名一致的 Book 结构化数据，执行 ISBN-10/13 校验，返回作者、出版社、年份和来源。保留不同版本候选，不把第一条自动写回书库；页面推荐书籍和验证码内容不作为 ISBN 依据。

普通浏览器 User-Agent，无 Cookie，禁止跨站重定向。请求启动间隔至少 2 秒，超时 12 秒，响应最多 2MB；建议列表缓存 7 天、详情 30 天，空结果 1 小时。访问验证、403、429 明确返回 blocked 并冷却 60 秒；网络或解析失败短缓存 15 秒，不误报为未找到图书。缓存写入独立 SQLite 表并跨重启保留。MCP 桥接为 ISBN 查询提供 60 秒请求等待，其余工具保持原超时。

70 项 Rust 测试通过，新增覆盖批量部分失败、重试、匹配、库存保护、批次大小、ISBN 提取及校验、HTML 元数据、同名版本保留、缓存复用与到期、受限结果缓存、非法 subjectId 拒绝及查询不修改图书。成功解析测试使用显式模拟 JSON/HTML，现场豆瓣访问结果另行记录，不能把模拟成功算作真实站点验收。

`scripts/agent-smoke.mjs --douban` 实际 HTTP/stdio MCP 验收通过：8 个工具发现、批量新增/复用/单条失败、缓存 ISBN 查询及既有导入、鉴权、撤销能力均通过。ISBN 缓存成功路径使用明确标记的隔离测试数据；另外以实际客户端请求豆瓣“ 三体 ”建议接口及 subject/2567698/，获得《三体》ISBN 9787536692930、刘慈欣、重庆出版社、2008 年，ISBN 校验通过。建议结果同时保留《三体Ⅱ》《三体Ⅲ》，未把其当作同一版书或自动入库。该次正常客户端请求成功；站点仍可能返回安全验证，不能保证所有网络环境始终可用。测试只使用临时书库，未向用户书库写入模拟或现场查询记录。

## 应用内 OpenCode 网页（2026-10-29）

设置 → Agent 接入 → 打开 OpenCode，直接展示应用内网页工作区，不再打开 PowerShell 或终端。沿用所选本机版或专用版，后台运行独立的 `opencode serve`，不控制用户的共享 OpenCode 服务。网页使用官方界面，保留会话、模型选择、提供商设置和权限交互；自动使用包含两个 Skill 与 MCP 配置的应用工作目录。

网页经独立的本地网关连接：仅监听 127.0.0.1，以随机临时 localhost 主机名限定访问，校验 Host 和 Origin；OpenCode 自身仍启用认证，服务口令仅由网关进程持有，不发到网页或写入配置包。网关透传 HTTP、流式消息与 WebSocket，保留上游 CSP 的其他规则，并限制嵌入来源。应用 API 的令牌不会转发给 OpenCode。

返回系统只隐藏网页，保留当前会话、滚动和未发送草稿；切换设置页签后再返回也复用已打开的实例。停止服务会提示当前任务中断及未发送草稿丢失；已经保存到 OpenCode 的会话可在重开服务后恢复。服务运行时禁止切换程序，避免关闭正在执行的实例。应用退出时通过 Windows Job 结束所管理的网关、OpenCode 及子进程。

已通过 67 项 Rust 测试、3 项网关测试及前端构建。真实本机 2.0.11、专用 2.2.0 分别验证隐藏启动与复用、网页访问、会话跨服务重启保留、程序切换保护、主动停止、应用进程退出后的子进程清理。验证脚本 `scripts/opencode-web-smoke.mjs` 使用独立配置与数据库，不调用模型推理。网页交互在完整应用验收页面检查新会话、自动工作目录、模型控件、返回与进入、未发送草稿保留和停止确认；未执行真实平台上架。

另外在隔离的专用版网页中选择界面列为免费的 Big Pickle，发送仅要求文字回复、禁止工具调用的连接测试，实际收到“网页连接成功”（界面显示 3 秒），证明输入、请求与回复链路可用。未发送业务操作指令。1360×880 与 1080×700 截图保存在 `.impeccable/review/opencode-web-desktop.jpg`、`opencode-web-min.jpg`，独立界面复查 disposition 为 ship；设计体系核对保持现有文件不变。该文字测试不代表整条图书经营流程已经完成平台验收。

## 订单发货与内部采购关联（2026-10-28）

入口：闲管家订单列表 → 发货，或订单详情 → 采购与物流。发货弹窗分为“填写物流”和“淘宝采购”，没有增加一级入口。前者不依赖采购单或已建货源，填写快递公司、单号并确认即可；后者允许手动打开淘宝购买，回填淘宝订单号、采购状态、可选实付金额、店铺、规格和内部备注。收件信息按需从销售订单读取，仅保留在当前窗口内存中，不自动发送给淘宝。

采购订单号、货源和备注仅存储在本地 purchase_attempts 及内部操作记录。关联采购与更新供应商发货状态都不会调用闲鱼写接口，也不会修改闲鱼商品、订单备注或给买家发送消息。只有用户在弹窗中勾选核对并点击“确认发货”，才调用既有闲管家发货接口；出站字段固定为销售订单号、快递编码、快递名称和物流单号四项。

内部流程为已下单待物流 → 待回传物流 → 闲鱼发货结果核查。采购物流录入后，销售订单仍为待发货；远端成功受理后再查询订单确认。超时、进程中断等未知发货结果保留核查状态，阻止盲目重发及改写采购或单号；发货执行期间也不允许并发改写物流。已识别的电子订单不能走实体发货。未映射的订单须由操作人明确确认实物商品。进行中售后、未付款、取消以及数量未知的订单不能新发货。

单笔销售订单保留一条有效采购关联，并保留取消/更换历史。同一采购单不重复关联另一销售订单；已下单的采购编号不可直接覆盖，需核实取消后重新关联。没有填写的采购成本仍为未知值，不按零核算。旧采购记录兼容，字段扩展使用现有 JSON，不清理历史数据。

验证：58 项 Rust 库测试通过，前端生产构建、API 服务及桌面程序构建通过。新增测试覆盖无采购直接填物流、未匹配订单手动确认、电子订单拒绝、重复采购关联、重启恢复、未知成本、取消清理旧物流和并发操作互斥。HTTP 模拟平台测试明确断言：内部保存不会触发平台调用；实际发货请求只有四个允许字段，采购单号、采购金额、供货店和内部备注不会进入任何远端请求。

使用 scripts/shipment-review.mjs 的模拟订单进行浏览器操作验收：从订单列表打开发货弹窗，保存物流、确认模拟发货并核查、保存淘宝采购、关闭重开恢复关联、供应商已发货而闲鱼仍待发货、按需读取收件信息、焦点循环及 Escape 关闭。1080×700 和 1360×880 下默认表单没有内部滚动或横向溢出；可选商品与备注按需展开。模拟“去淘宝购买”只记录本地动作，没有打开实际淘宝或提交采购。截图为 shipment-taobao-minimum.png、shipment-taobao-desktop.png、shipment-manual-minimum.png。

当前淘宝采购状态及单号由用户手动更新，没有实现淘宝已购订单自动同步。未使用真实销售订单执行平台发货；真实账号验收不能由上述模拟测试替代。

## 一键找最低价（2026-10-27）

入口：图书详情 → 货源 → 一键找最低价。优先使用 ISBN，否则组合书名、作者、版次；向淘宝请求价格升序检索。按用户提供的 2026-10-27 HTML 修正为滚动采集，不再按 44 条偏移量构造分页 URL。追加和虚拟列表中的商品均累计去重，最多 3 个保存批次（每批最多 60 个候选）；到达当前加载边界后结束。只有真实可用的主结果“下一页”按钮存在时才点击，排除顶部轮播分页；无响应时暂停，不重复点击。使用已有内嵌浏览器登录会话，不另存账号密码。

价格按 `priceInt` 与 `priceFloat` 分别读取，避免整数价后接付款人数而误解析；使用 `shopNameText` 读取店铺，并保留“补贴后”等 `priceDesc` 标签。比较同时展示本次候选与已有淘宝货源。展示价仅供筛选；只有已确认版本规格、品相与本书一致、支持代发，且采购价和运费均明确的可用货源，才计入“最低已核验含运费价”。未填写图书品相时，不生成已核验最低价。核验时间可见，候选可直接进入编辑弹窗。结果仅代表采集范围和已有报价，不承诺全网最低，也不推断优惠券、其他 SKU 或未知运费。

任务按图书持久保存，带请求 ID，支持停止、继续和重启后继续；过期回传、乱序批次、停止或暂停后的新批次不会写入。恢复时跳过已保存的商品，继续滚动。沿用旧任务 `pagesDone` 的存储以保留历史，接口另外提供 `batchesDone`，页面仅显示候选数量和滚动采集。复用一个淘宝窗口，切换另一图书比价时暂停原任务。登录、验证遮罩、页面未就绪或超时会暂停并保留已采集结果。检索结果不会覆盖已核验报价或自动新建图书。

旧书库首次加入比价表前执行备份；新增 `price_searches` 表保存采集快照和进度。使用整数分比较采购价加运费，未知值不按零处理。
